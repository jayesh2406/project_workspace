# Project Workspace — Multi-Page Business Website

A React + Vite frontend project containing a multi-page business website experience.

## Features

- Home and company information pages
- Services and fleet showcase sections
- Shop / product browsing experience
- Partnership and contact sections
- Reusable navigation, page wrapper, cards, and footer components
- Route-based navigation with React Router

## Tech Stack

- React
- Vite
- JavaScript
- React Router
- Lucide React

## Run Locally

The application source is located in `project_workspace/project_workspace/`.

```bash
cd project_workspace/project_workspace
npm install
npm run dev
```

Create a production build:

```bash
npm run build
```
